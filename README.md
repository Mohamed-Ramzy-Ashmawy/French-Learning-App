# French Learning App

An app that quizes user on noun phrases [the combination of an article (e.g. la, le, un, des) and a noun]

## 🛠 Features
* **No-Repeat Logic:** Uses a tracking system to ensure you don't see the same word twice in a row.
* **JSON-Based:** All vocabulary is stored in `words.json` for easy updates.
* **Single-Language:** Currently supports a French module.

## 🚀 Getting Started

### Prerequisites
* Python 3.10+ (Tested on Linux Mint)
* No external libraries required (uses standard `json` and `random` modules).
